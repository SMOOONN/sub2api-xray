Sub2API Xray v0.2.18-xray6

同步官方 v0.2.18，保留 Xray 代理、私有资源和重试过滤器能力。

- 支持 Gemini 显式上下文缓存，包括 AI Studio、Agent Platform（Vertex）与兼容上游，完善缓存修改、过期恢复和存储计费。
- 增强 Vertex API Key 与服务账号支持，补齐模型同步、模型查询、配额和异常恢复。
- 分组名称与描述支持多语言，私有分组同步支持；订阅页面保留资源池健康信息。
- 更新 Claude Haiku 5.5、Gemini 4 Argon 等模型适配，完善思考内容、工具图片与协议转换。
- 修复流式中断后的用量结算、Codex 重试、模型限流与账号调度问题，保留 Xray 重试过滤器行为。
- 修复支付通知确认、退款状态处理与 Stripe 订单恢复，更新相关模型计费。
- GPT-5.5 订阅账号按官方规则退役，API Key 账号继续支持；Grok Fast 使用标准版两倍价格。
- Gemini/Antigravity 存量分组自动开启生图；混合分组需手动开启。图片转存仅接受公开网络图片地址，拒绝内网、回环地址和非图片响应。

升级方式

- 安装包：从本 Release 下载对应平台文件，使用 `checksums.txt` 核对；也可获取 `v0.2.18-xray6` Tag 从源码构建，步骤见 README。
- Docker：将现有 Compose 的应用镜像设为 `ghcr.io/smooonn/sub2api-xray:0.2.18-xray6`，拉取镜像并仅更新应用服务。镜像支持 Linux amd64 和 arm64。
- 本版本包含数据库迁移。升级前请备份 PostgreSQL、Redis 和应用数据，应用启动后会自动执行迁移。
