# v0.2.21-xray7

同步官方 **Sub2API v0.2.21**，保留 Xray 代理、私有资源及重试过滤器。

## 本次更新

- 新增 Claude Fable 5.2、Mythos 5.2 支持，完善模型适配与计费。
- 增加 OpenAI 缓存写入分桶及独立定价，修复转发、并发和令牌刷新问题。
- 优化账号、密钥列表与系统设置，统一小按钮，普通用户侧栏隐藏版本。
- 修复私有 Antigravity 模型同步，补齐出站保护及 SOCKS 代理超时。
- 升级 Go 至 1.27.4，修复 HTTP/1 竞态安全问题。

## 升级方式

升级前备份数据库和应用数据。Docker 用户拉取 `ghcr.io/smooonn/sub2api-xray:0.2.21-xray7` 后重新创建应用容器；非 Docker 用户通过程序在线更新或下载对应平台安装包升级。

本次新增两个数据库迁移，启动时自动执行。用量记录覆盖索引采用并发创建；数据量较大时，首次启动可能需要更长时间。
