# Sub2API Xray v0.2.15-xray6 更新说明

> 此 Tag 仅恢复历史源码，本仓库不为该版本构建安装包或镜像。安装和升级请使用 [最新正式版](https://github.com/SMOOONN/sub2api-xray/releases/latest)。

本版本同步官方 v0.2.15 及其版本同步提交，保留 Xray 用户资源、代理运行时和重试过滤器功能。

## 官方功能同步

- 新增 TypeSafe、System One、Command Code 和 Cline 平台支持，账号表单和模型同步按平台能力展示。
- 支持 GPT-6.1 Sol、Codex 远程模型目录与当前订阅套餐识别，新增 Claude 原生额度重置操作。
- 账号筛选更紧凑，支持快捷调整优先级；API Key 可按分组排序，并可限制创建数量和频率。
- 充值支持按金额配置赠送或折扣阶梯，用量记录和运维监控新增输出速度统计。
- 完善协议转发、工具调用、账号调度及弹窗交互，更新 Go 和网络依赖。

## Xray 修复与优化

- 重试监控显示每次尝试的独立时间，精确到毫秒，并修复切换筛选条件时的旧结果覆盖问题。
- 过滤规则管理提供五页使用说明，关闭后可从页头重新查看。
- 订阅源管理采用完整列表，新增和编辑使用独立弹窗。
- 保留私有资源隔离、订阅分发、Xray 和 sing-box 节点支持，以及已有重试次数和间隔设置。

## 升级方式

- 历史源码：获取本 Tag 查看源码；本仓库不为该版本构建安装包，安装和升级请使用最新正式版。
- Docker：请使用最新正式版提供的 `ghcr.io/smooonn/sub2api-xray` 镜像，并保持现有配置和数据。
- 本版本包含数据库迁移。升级前请备份 PostgreSQL、Redis 和应用数据，应用启动后会自动执行迁移。
