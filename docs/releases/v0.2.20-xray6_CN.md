# v0.2.20-xray6

同步官方 **Sub2API v0.2.20**，保留 Xray 代理、私有资源及重试过滤器。

## 本轮更新

- 为请求体内存、上传和响应读写、后台任务增加资源限制，减少大请求和慢连接对网关的影响，并优化请求解析与流式转发。
- 完善管理员 API Key 的统计、OpenAI OAuth、邀请等权限及中英文说明，新增需确认后开启的全权兼容模式。
- 新增注册邮箱精确黑名单，支持批量录入和 Gmail 别名匹配，可选择停用命中的已注册用户；批量停用同步处置其私有资源和已分配订阅。
- 支持 GPT Image 2.6 原生图片链路与编辑参数，OpenAI 生图账号可按 1K／2K／4K 尺寸档位分流。
- 更新 GPT-6.1 Terra 的上下文、推理参数及长上下文计费规则；Codex 与 CC Switch 密钥导出默认使用 GPT-6.1 Sol。
- 改进 Antigravity 配额窗口展示和模型冷却；文本连接测试保留自定义提示词，并采用官方 256 token 输出上限。
- 修复多平台转发中的响应内容、工具媒体、空 instructions、流式读取和错误分类问题，补齐 WebSocket 首 token 计时及图片选号修复。
- 使用记录 CSV 导出改为每页 1000 条，遇到限流时按 Retry-After 等待并重试。
- 更新后端压缩依赖，修复相关依赖的已知安全问题。

## 升级方式

升级前备份数据库和应用数据。Docker 用户拉取 `ghcr.io/smooonn/sub2api-xray:0.2.20-xray6` 后重新创建应用容器；非 Docker 用户通过程序在线更新或下载对应平台安装包升级。

本轮相较 `0.2.19-xray6` 没有新增数据库迁移。请求体合计内存预算默认 1GiB，上传读取及响应写入停滞超时默认 120 秒；请按实例资源和使用场景调整，详见[资源设置说明](https://github.com/SMOOONN/sub2api-xray/blob/main/deploy/EDGE_SECURITY.md)。

已保存的模型白名单和映射不会自动扩大；需要使用新的图片模型时，请在相应账号或分组中添加。
