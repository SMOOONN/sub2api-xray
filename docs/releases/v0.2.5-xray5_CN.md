# Sub2API Xray v0.2.5-xray5 更新说明

> 此 Tag 仅恢复历史源码，本仓库不为该版本构建安装包或镜像。安装和升级请使用 [最新正式版](https://github.com/SMOOONN/sub2api-xray/releases/latest)。

发布日期：2026-09-18

本版本同步官方 v0.2.5，Xray 自身能力全部保留。

## 新增功能：普通用户可自建 OpenCode 与 MiniMax 账号

- 「我的资源 - 我的账号」的可添加平台新增 OpenCode 与 MiniMax，OpenCode 可选择 Zen 或 GO 账号类型。
- 两个平台沿用普通用户自建账号一贯的出站目标限制，可用范围与已有平台保持一致。
- 管理员侧的账号管理不受影响。

## 官方新功能

- 新增 OpenCode 平台，账号分 Zen 与 GO 两种类型，连通性测试会按账号的模型映射进行。
- 新增「站点类型」三态开关：关闭订阅后，用户端会一并收起所有订阅入口与相关文案。
- 订阅管理支持批量操作，API Key 管理支持批量编辑，用户管理支持批量删除所选用户。
- API Key 的分组选择可按提供方筛选。
- 注册流程新增确认密码。
- 运维监控新增全平台 Token 请求统计。
- Antigravity 新增 Gemini 3.7 Flash 与 Gemini 3.8 Flash 模型支持。
- OpenAI OAuth 的图像请求改走原生 Codex Images 通道。
- Ollama Cloud 用量窗口的限流重置改为异步执行。
- 网关的模型列表改为从可见目录获取。
- 支持隐藏自定义页面的打开按钮。
- 若干上游协议兼容、调度选号与稳定性修复。

## 升级方式

现行安装和升级以 [SMOOONN/sub2api-xray Release 页面](https://github.com/SMOOONN/sub2api-xray/releases)实际已发布的版本为准，下面的 `<已发布标签>` 需替换为可用的镜像标签。本文版本记录不表示当前仓库已发布同名版本。

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:<已发布标签>`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/SMOOONN/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
- 其中一条官方迁移会删除日、周、月三项额度全部为空的用户平台额度记录。这类记录本就不产生任何限制，删除后行为不变；如需保留，请在升级前自行备份 `user_platform_quotas` 表。
- 更新完成后请先重启服务，再执行回退操作。
