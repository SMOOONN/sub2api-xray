# Sub2API Xray v0.2.5-xray6 更新说明

本版本基于官方 v0.2.5，新增重试过滤器及配套的规则管理、绑定和监控功能。

## 新增重试过滤器

- 支持创建、编辑、复制和启停规则集，拖拽调整规则优先级；可分别绑定账号、请求分组或设置为全局默认，按账号 → 请求分组 → 全局的顺序生效。
- 支持按状态码及号段、正文关键词、上游错误码和模型名匹配，提供“任一条件命中”和“全部条件命中”两种方式。
- 支持同账号重试、切换账号、直接返回和仅观察四种动作，可设置同账号重试次数及间隔，或自定义终止时的返回文案。
- 支持识别空请求、正常完成但没有有效输出的响应，以及有效输出前的异常断流。流内上游错误也可在有效输出前按规则处理。
- 新增重试监控，可查看规则命中、重试和账号切换决策及错误详情，并按模型、账号、分组、规则等条件筛选。
- 规则编辑、监控筛选和设置项沿用统一界面组件，支持下拉框键盘选择与 Esc 关闭菜单。

## 使用说明

- 重试过滤器默认关闭，需在系统设置中启用并绑定规则集；未匹配的失败保留原有处理方式。
- 当前适用于开启池模式的 API Key 和 Bedrock 账号。WebSocket 同账号重试仍需满足上游返回 429 且提供重试窗口的条件。
- 空请求仅“直接返回”动作可改变处理结果；已向客户端输出有效内容后，不再透明重试并拼接另一条回答。

## 升级方式

现行安装和升级以 [SMOOONN/sub2api-xray Release 页面](https://github.com/SMOOONN/sub2api-xray/releases)实际已发布的版本为准，下面的 `<已发布标签>` 需替换为可用的镜像标签。本文版本记录不表示当前仓库已发布同名版本。

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:<已发布标签>`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/SMOOONN/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含数据库迁移。升级前请备份 PostgreSQL、Redis 和应用数据，应用启动后会自动执行迁移。
