# v0.2.24-xray7

同步官方 **Sub2API v0.2.24**，保留 Xray 代理、私有资源和重试过滤器。

## 本次更新

- 加强网关请求校验。JSON 请求、WebSocket 消息和受保护的表单字段出现重复声明时会被拒绝。客户端应确保每个字段只发送一次。
- 网页搜索模拟新增 Exa 服务商，兼容响应可返回搜索来源。模型广场支持复制模型 ID。
- 降低网关解析大请求时的重复开销。改进上游超时换号、OAuth 凭据刷新和 Antigravity 额度查询。
- 账号页新增 Claude 窗口费用估算和频繁刷新提醒。批量编辑透传设置时，可选择是否同时修改模型过滤。

## 升级方式

升级前备份数据库和应用数据。Docker 用户拉取 `ghcr.io/smooonn/sub2api-xray:0.2.24-xray7` 后重新创建应用容器。其他安装方式可通过程序在线更新，或下载对应平台的安装包。
