# Sub2API Xray v0.1.177-xray4 更新说明

发布日期：2026-08-16

`v0.1.177-xray4` 同步官方 `v0.1.177` 及其对应的最新 `main` 提交，并继续保留 Xray 的用户私有资源池、订阅分发、代理绑定、内置 Xray / sing-box 运行时和独立更新链路。

## 官方功能同步

- Codex 请求补齐会话级 `remote_compaction_v2` beta 功能标识，与官方客户端行为保持一致。
- 账号“压缩测试”改用原生 remote compaction v2 探测；原生 v2 请求继续使用 `/responses`，不再被旧压缩路由改写。
- 支持向客户端回传 `x-codex-turn-state`，并校验回合状态来源，阻止状态在不同账号之间错误回显。
- Codex OAuth 账号的指纹收敛改为显式启用，默认不再静默改写客户端标识；透传路径同步遵循账号配置。
- 同步账号创建、编辑和批量编辑界面的指纹收敛选项与中英文说明。

## 版本衔接

- `v0.1.176-xray4` 已同步当时官方最新 `main`，因此官方 `v0.1.177` 说明中的分组日用量汇总、Grok 计费修复和账号页自动刷新修复已在上一 Xray 版本中包含，本版本继续保留这些能力。
- 本次从 `v0.1.176-xray4` 升级不新增数据库迁移，现有数据库、Redis 和应用数据可原位复用。

## Xray 兼容范围

- 保留管理员与普通用户之间的资源所有权隔离，以及用户自有账号、代理、兑换码和分组访问边界。
- 保留 Xray 分享链接、机场订阅、Sing-box / Clash 配置导入和运行时生命周期管理。
- 保留独立仓库、独立 GHCR 镜像和测试实例在线更新流程；项目文档继续移除上游赞助推广区块。

- 测试服务器：`http://10.0.0.128:18082`；公开设置接口返回 HTTP 200，当前版本为 `0.1.177-xray4`。
- 自动化验证已通过：前端 605 个测试套件、1,636 项测试，`vue-tsc`，Vite 生产构建，以及 `go test -tags=unit ./...`。
- 内置浏览器已在桌面 `1280x720` 和窄屏 `390x844` 检查公开首页、版本信息、Dashboard、账号管理、我的账号、分组、使用记录、IP 管理、我的代理、移动端导航、筛选下拉及主要创建/编辑弹窗；弹窗内部滚动和底部操作栏正常，控制台无应用错误或警告。
- Codex 指纹收敛选项已核对：创建和编辑 OpenAI OAuth 账号默认显示“关闭（透传，默认）”，并提供“仅设备 / 设备+会话 / 完全收敛”。

## 行为变更

- 未显式配置指纹收敛的 Codex OAuth 账号升级后默认恢复透传客户端原始标识。
- 已显式选择“关闭 / 仅设备 / 设备+会话 / 完全收敛”档位的账号保持原有配置；需要继续收敛的新账号应在账号设置中明确选择档位。

## 升级说明

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:0.1.177-xray4`

- 升级前仍建议保留 PostgreSQL、Redis 和应用数据备份。
