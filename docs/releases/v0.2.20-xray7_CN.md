# v0.2.20-xray7

基于官方 **Sub2API v0.2.20**，本次更新重试过滤器的规则管理界面。

## 本次更新

- 重新设计规则管理布局，拆分为“规则列表／应用范围／基本设置”三个标签页，减少单页配置堆叠。
- 新增和编辑规则使用居中弹窗，按“匹配条件→命中动作”分步配置，按需展示条件及动作设置。
- 优化规则列表，支持搜索、拖动和上下移动排序；简化启停、复制、删除入口，将全局默认设置改为紧凑按钮。
- 完善编辑保护：切换标签保留草稿，切换规则集或关闭已修改的规则弹窗时提醒；替换已有绑定前确认，保存失败保留输入。
- 精简规则管理与重试监控的说明文字，缩短标题区留白，统一标题与操作按钮对齐。

## 升级方式

升级前备份数据库和应用数据。Docker 用户拉取 `ghcr.io/smooonn/sub2api-xray:0.2.20-xray7` 后重新创建应用容器；非 Docker 用户通过程序在线更新或下载对应平台安装包升级。

本次相较 `0.2.20-xray6` 没有新增数据库迁移，保留现有重试规则及账号、分组绑定。
