# v0.2.19-xray6

同步官方 **Sub2API v0.2.19**，保留 Xray 代理、私有资源及重试过滤器。

## 本轮更新

- 新增按操作和资源范围授权的管理员 API Key，支持有效期、IP 白名单及撤销审计。
- OpenAI 和 Composite 分组支持按实际出图张数计费，默认关闭；更新模型支持、Grok 模型目录诊断及 Gemini 同账号重试配置。
- 普通用户可查看自有 Grok 账号的模型目录诊断，并同步自有账号模型；权限和数据仍按账号所有权隔离。
- “我的代理”的订阅源管理与管理员界面统一，提供独立新增／编辑弹窗、分页、同步状态及操作按钮。
- 合入官方图片计费、缓存用量、模型映射、分页和上传限制等修复。
- 修复绑定显式缓存时，重试过滤器的终止状态和提示被上游原始错误覆盖的问题。
- 新增默认关闭的管理 MCP，支持 OAuth 授权、个人／管理员范围、只读／读写权限及授权撤销。
- 修复 OpenAI OAuth 非流式响应透传，正确处理上游事件流及未完成、取消的响应。
- 更新国际化、URI 解码及重定向依赖，修复相关依赖的已知安全漏洞。

## 升级方式

升级前备份数据库和应用数据。Docker 用户拉取 `ghcr.io/smooonn/sub2api-xray:0.2.19-xray6` 后重新创建应用容器；非 Docker 用户通过程序在线更新或下载对应平台安装包升级。

本版启动时自动执行新增数据库迁移。Gemini 默认模型列表移除了旧 2.x 系列，仍需使用的账号请在白名单或模型映射中配置。

管理 MCP 需显式配置可信的公开地址后启用，未配置时保持关闭。

本次为同名安全重发。已安装 `0.2.19-xray6` 的用户请重新拉取镜像并重建应用容器，或重新下载并替换安装包；同名版本不会自动触发在线更新提示。
