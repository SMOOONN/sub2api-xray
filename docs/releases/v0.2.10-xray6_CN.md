# Sub2API Xray v0.2.10-xray6 更新说明

> 此 Tag 仅恢复历史源码，本仓库不为该版本构建安装包或镜像。安装和升级请使用 [最新正式版](https://github.com/SMOOONN/sub2api-xray/releases/latest)。

本版本同步官方 v0.2.10，以该版本发布 Tag 为基准，保留 Xray 的重试过滤器及用户资源管理功能。

## 官方功能同步

- 扩展模型与上游支持：新增 Seedance/Ark 视频任务接口，支持 GPT-6 Sol/Luna、Claude Opus/Sonnet 5.5 和 Grok 4.7。
- 增强账号额度管理：新增 OpenCode Go 用量窗口、Codex credits 与邀请管理、Claude 原生重置额度查询。
- 增加推理强度计费倍率，仪表盘可切换 Token 用量与消费趋势，分组模型白名单支持更灵活的通配匹配。
- 完善风控与客户端兼容：增加独立 TypeSafe 审核引擎配置、风控用户白名单和 Claude Code 客户端版本同步。
- 增加月度备份归档及独立保留策略，完善返利线下提现登记和兑换记录分页。
- 增强插件宿主服务、账号目录与状态查询能力；简易模式新增默认分组自动创建和 API Key 消费窗口限制开关。

## 修复与优化

- 改善流式用量统计和 Antigravity 首段输出前保活。
- 修复复合分组路由、多个工具名改写和模型白名单与模型映射冲突等问题。
- 修复账号用量面板切换时的状态串用，改善弹窗交互。

## 升级方式

- 历史源码：获取本 Tag 查看源码；本仓库不为该版本构建安装包，安装和升级请使用最新正式版。
- Docker：请使用最新正式版提供的 `ghcr.io/smooonn/sub2api-xray` 镜像，并保持现有配置和数据。
- 本版本包含数据库迁移。升级前请备份 PostgreSQL、Redis 和应用数据，应用启动后会自动执行迁移。
